# 🌍 GeoMind

Интерактивный тренажёр географической памяти. Выбирай категорию и сложность,
отвечай на вопросы, зарабатывай XP, прокачивай уровень и следи за серией тренировок.

## Возможности (v0.3)

- **Категории** — две доступные: 🚩 «Флаги стран» и 🌎 «Страны и столицы».
  Остальные (карта, города, горы, моря, валюты) помечены «Скоро».
- **Сложность** — перед каждой тренировкой выбирается один из трёх уровней:
  🟢 Лёгкая (+10 XP), 🟡 Средняя (+20 XP), 🔴 Сложная (+30 XP).
  Уровни отличаются не только наградой, но и набором вопросов и вариантов:
  лёгкие — известные страны, средние — похожие флаги/столицы-соседи,
  сложные — редкие и легко перепутываемые.
- **Флаги стран** — 133 страны с эмодзи-флагами (40 лёгких, 47 средних, 46 сложных):
  вопрос «Какой стране принадлежит этот флаг?» с 4 вариантами.
- **Страны и столицы** — 120 стран с флагами (46/43/31 по сложности), работает
  на любом уровне сложности как и раньше.
- **XP и уровни** — XP копится во всех категориях и сложностях в общий запас;
  уровни с растущими порогами (1 → 0, 2 → 100, 3 → 250, 4 → 450, 5 → 700 XP …).
  После тренировки — анимированное начисление XP, прогресс уровня
  и плашка «Новый уровень!».
- **Статистика** — экран «Статистика» с общими результатами, разбивкой
  по сложности и по категориям, а также историей тренировок
  (дата, категория, сложность, счёт, точность, время, XP).
- **Прогресс хранится** в `localStorage` и переживает перезагрузку страницы.

## Запуск

Приложение не требует сборки и зависимостей. Достаточно открыть `index.html` в браузере
(или запустить любой статический сервер, например `npx serve` или `perl tools/serve.pl 8080`).

## Структура проекта

```
index.html            — точка входа
css/
  base.css            — токены, сброс, кнопки, карточки, анимации, полоса уровня
  screens.css         — стили экранов (главный / настройка / тренировка / результат / статистика)
js/
  core/
    config.js         — настройки (длина тренировки, ключи)
    storage.js        — безопасная обёртка над localStorage
    levels.js         — система уровней: пороги XP, прогресс до следующего уровня
    stats.js          — модель статистики: XP, агрегаты по категориям/сложности, история
    training.js       — движок тренировки: категория + сложность, таймер, начисление XP
  data/
    difficulties.js   — уровни сложности и награды (+10/+20/+30 XP)
    capitals.js       — база стран и столиц (120 записей, с флагами и сложностью)
    flags.js          — база флагов (133 записи, с флагами и сложностью)
    questions.js      — универсальный генератор вопросов (категория × сложность)
    categories.js     — категории тренировок (доступные и «Скоро»)
  ui/
    dom.js            — хелперы создания DOM, форматирование дат и чисел
    screens.js        — рендеринг экранов
  app.js              — точка входа
```

## Как расширять

- **Добавить страну в категорию** — дополнить `CAPITALS` в `js/data/capitals.js`
  или `FLAGS` в `js/data/flags.js` (обязательно с `difficulty`).
- **Изменить награду за сложность** — поменять `xpPerCorrect` в `js/data/difficulties.js`.
- **Изменить прогрессию уровней** — поменять `FIRST_STEP` / `STEP_GROWTH` / `MAX_LEVEL`
  в `js/core/levels.js` (пороги пересчитаются автоматически).
- **Добавить категорию** — добавить запись в `js/data/categories.js`, базу записей
  с `difficulty` и зарегистрировать построитель вопроса в `js/data/questions.js`.
- **Прогресс пользователя** хранится в `localStorage` под ключом `geomind:stats:v1`.

> Примечание: на Windows десктопные браузеры не всегда умеют рисовать
> эмодзи-флаги (показывают буквы кода страны). На телефонах и в большинстве
> браузеров macOS/Linux флаги отображаются корректно.
