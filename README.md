# 🌍 GeoMind

Интерактивный тренажёр географической памяти. Выбирай категорию и сложность,
отвечай на вопросы, зарабатывай XP, прокачивай уровень и следи за серией тренировок.

## Возможности

- **Категории** — две доступные: 🚩 «Флаги стран» и 🌎 «Страны и столицы».
  Остальные (карта, города, горы, моря, валюты) помечены «Скоро».
- **Сложность** — перед каждой тренировкой выбирается один из трёх уровней:
  🟢 Лёгкая (+10 XP), 🟡 Средняя (+20 XP), 🔴 Сложная (+30 XP).
  Уровни отличаются не только наградой, но и набором вопросов и вариантов:
  лёгкие — известные страны, средние — похожие флаги/столицы-соседи,
  сложные — редкие и легко перепутываемые.
- **Флаги стран** — 133 страны (40 лёгких, 47 средних, 46 сложных).
  Два типа вопросов: «Какой стране принадлежит этот флаг?» (флаг — вопрос,
  варианты — страны) и «Какой флаг принадлежит Германии?» (варианты —
  флаги-картинки).
- **Страны и столицы** — 120 стран (46/43/31 по сложности), работает
  на любом уровне сложности.
- **Режимы** — классический (10 / 20 / 50 вопросов) и ♾️ бесконечный,
  который продолжается, пока не нажмёшь «Завершить тренировку».
- **XP и уровни** — XP копится во всех категориях и сложностях в общий запас;
  уровни с растущими порогами (1 → 0, 2 → 100, 3 → 250, 4 → 450, 5 → 700 XP …).
  После тренировки — анимированное начисление XP, прогресс уровня
  и плашка «Новый уровень!».
- **Статистика** — экран «Статистика» с общими результатами, разбивкой
  по сложности и по категориям, историей тренировок и разделом «Мои ошибки»
  с возможностью 🔁 повторить ошибки.
- **Прогресс хранится** в `localStorage` (`geomind:stats:v1`) и переживает
  перезагрузку страницы.

## Флаги — локальные SVG, без внешних сервисов

Все флаги лежат **внутри проекта**, в `assets/flags/`, по двухбуквенному
ISO 3166-1 alpha-2 коду: `assets/flags/ru.svg`, `assets/flags/de.svg`,
`assets/flags/jp.svg` и т. д. (149 файлов). Приложение не обращается ни к каким
внешним сайтам, поэтому флаги работают без интернета и не зависят от чужого CDN.

Схема отображения:

```
название страны  →  ISO-код  →  <base>/assets/flags/{code}.svg
```

- Соответствие «страна → код» — `js/data/flag-codes.js` (единый источник истины).
- Построение пути и создание `<img>` — `js/lib/flag-image.js` (единственный слой,
  который знает, откуда берётся картинка).
- Базовый путь вычисляется от `document.baseURI`, поэтому корректно работает
  и локально (`file://`), и на GitHub Pages в подпапке
  (`https://kirilltolich.github.io/geomind/assets/flags/...`).
- Unicode-флаги (🇷🇺 и подобные) не используются нигде: на Windows браузеры
  рисуют их как буквы кода страны. Если для страны нет кода или SVG, показывается
  нейтральная заглушка.

### Проверка целостности

```bash
node tools/verify-flags.js
```

Проверяет, что у каждой страны есть ISO-код, для каждого кода существует
локальный SVG, нет ссылок на внешние сервисы, дубликатов кодов, битых путей
и Unicode-флагов.

### Перескачать флаги (только при разработке)

```bash
node tools/fetch-flags.js          # скачать отсутствующие
node tools/fetch-flags.js --force  # перекачать все
```

## Запуск

Приложение не требует сборки и зависимостей. Достаточно открыть `index.html`
в браузере (или запустить любой статический сервер, например
`npx serve` или `perl tools/serve.pl 8080`).

Публикация на GitHub Pages — из ветки `master`, каталог `/` (корень репозитория).

## Структура проекта

```
index.html            — точка входа
assets/
  flags/              — локальные SVG-флаги (149 файлов, ISO-коды)
css/
  base.css            — токены, сброс, кнопки, карточки, анимации, полоса уровня
  screens.css         — стили экранов (главный / настройка / тренировка / результат / статистика)
js/
  core/
    config.js         — настройки (длина тренировки, ключи)
    storage.js        — безопасная обёртка над localStorage
    levels.js         — система уровней: пороги XP, прогресс до следующего уровня
    stats.js          — модель статистики: XP, агрегаты по категориям/сложности, история, ошибки
    training.js       — движок тренировки: категория + сложность, режимы, таймер, начисление XP
  data/
    difficulties.js   — уровни сложности и награды (+10/+20/+30 XP)
    flag-codes.js     — соответствие «страна → ISO-код» (для локальных флагов)
    capitals.js       — база стран и столиц (120 записей, с кодом флага и сложностью)
    flags.js          — база флагов (133 записи, с кодом флага и сложностью)
    questions.js      — универсальный генератор вопросов (категория × сложность)
    categories.js     — категории тренировок (доступные и «Скоро»)
  lib/
    flag-image.js     — слой отображения флагов: страна → код → локальный SVG
  ui/
    dom.js            — хелперы создания DOM, форматирование дат и чисел
    screens.js        — рендеринг экранов
  app.js              — точка входа
tools/
  fetch-flags.js      — разовая загрузка SVG-флагов в assets/flags (при разработке)
  verify-flags.js     — проверка целостности системы флагов
  serve.pl            — простой локальный статический сервер
```

## Как расширять

- **Добавить страну** — добавить запись в `CAPITALS` (`js/data/capitals.js`) или
  `FLAGS` (`js/data/flags.js`) с полями `difficulty` и `code`; добавить код
  в `js/data/flag-codes.js` и положить `assets/flags/{code}.svg`.
- **Изменить награду за сложность** — поменять `xpPerCorrect` в `js/data/difficulties.js`.
- **Изменить прогрессию уровней** — поменять `FIRST_STEP` / `STEP_GROWTH` / `MAX_LEVEL`
  в `js/core/levels.js` (пороги пересчитаются автоматически).
- **Добавить категорию** — добавить запись в `js/data/categories.js`, базу записей
  с `difficulty` и зарегистрировать построитель вопроса в `js/data/questions.js`.
- **Заменить флаги** — достаточно заменить файлы в `assets/flags/`; логика вопросов
  и экранов не меняется.
- **Прогресс пользователя** хранится в `localStorage` под ключом `geomind:stats:v1`.
